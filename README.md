# TikhonovVladimir-Project-4
This is fourth project from Tikhonov Vladimir
---------------------------------------------
Этот проект представляет собой курс валют - евро, доллара и юани.
Чтобы открыть программу, необходимо запустить Launch.py
После этого, нажмите на кнопку "Начать работу"
Затем, Вам открывается основное окно. Если, не вводя ничего в поле, нажать на одну из валют, то откроется график выбранной валюты.
Если ввести дату в поле, то при нажатии на валюту и наличии даты в History.py, над полем Вам покажется курс этой валюты в тот день.
