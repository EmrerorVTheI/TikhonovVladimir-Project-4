# TikhonovVladimir-Project-4
This is fourth project from Tikhonov Vladimir
---------------------------------------------
Этот проект представляет собой курс валют - евро, доллара и юани.
Чтобы открыть программу, необходимо запустить Launch.py
После этого, нажмите на кнопку "Начать работу"
Затем, Вам открывается основное окно (как в windo.png). Если, не вводя ничего в поле, нажать на одну из валют, то откроется график выбранной валюты. Например, при нажатие на EUR, Вам откроется график курса евро (как в currenc.png)
Если ввести дату в поле, то при нажатии на валюту и наличии даты в History.py, над полем Вам покажется курс этой валюты в тот день. Например, введя 14.10.2025 и нажав на EUR, Вы получите курс евро на 14 октября 2025 года (как в oneda.png)
